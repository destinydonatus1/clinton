# Clinton Restaurant — Continental Cuisine 🍽️✨

A luxury, sophisticated, and fully responsive website for **Clinton Restaurant**, specializing in Michelin-standard Continental Gastronomy.

![Clinton Restaurant Crest](assets/images/logo-crest.svg)

---

## 🌟 Visual Identity & Color Palette

- **Charcoal Black (`#20201D`):** Dramatic nocturnal dining backgrounds and surface elevations.
- **Mustard Gold (`#E8B91B`):** Buttons, crest accents, active navigation states, and borders.
- **Warm Cream (`#F5F0E6`):** Elegant high-legibility typography and soft contrast.
- **Pure White (`#FFFFFF`):** Crisp headings and highlighted details.
- **Muted Olive (`#77764A`):** Terroir notes and sommelier vintage pairings.

---

## 🏛️ Pages & Features

1. **Home (`index.html`):**
   - Slider Revolution-inspired Cinematic Hero Slider with Ken Burns effect, timer progress bar, and touch gestures.
   - The Clinton Philosophy (3 Gastronomic Pillars).
   - Interactive Menu Showcase with category filters (Starters, Mains, Pastas, Desserts).
   - The Clinton Experience & Dining Salons showcase.
   - Critic Accolades & Reviews by *Le Guide Gastronomique*.
   - On-page instant booking engine.

2. **About Us (`about.html`):**
   - The Clinton Heritage & Founding story since 2012.
   - Executive Chef Clinton Vance showcase & signature.
   - Historical milestone timeline.
   - Sustainable terroir sourcing.

3. **Our Services (`services.html`):**
   - 6 Luxury offerings (Haute Degustation, Private VIP Salons, Luxury Catering, Sommelier Masterclasses, Chef's Table, Full Restaurant Buyouts).
   - Private event proposal inquiry form.
   - Interactive FAQ accordion.

4. **Contact Us (`contact.html`):**
   - Master interactive table reservation engine with instant confirmation code generation and printable voucher.
   - Concierge desk contact, opening hours, valet parking, and location map.

---

## 🚀 Local Setup & Preview

Open `index.html` directly in any modern browser, or run a local static server:

```bash
# Python
python -m http.server 8080

# Node.js
npx serve .
```
Navigate to `http://localhost:8080`.
